# Containerizing a RAG API

## 🛠️ Tech Stack
**Technologies:** `Docker, Dockerfile, Python, FastAPI`

## 📖 Project Overview
Packaged a locally developed Python RAG API into a Docker container to ensure standardized, environment-agnostic deployment.

## 🚀 Key Learnings
* Configuration and deployment of `Docker, Dockerfile, Python, FastAPI` in a production-like environment.
* Deep-dive analysis of system logs and network traffic.
* Documentation of technical workflows for architectural clarity.
