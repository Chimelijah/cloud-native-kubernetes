# Declarative Kubernetes Deployments

## 🛠️ Tech Stack
**Technologies:** `Kubernetes (kubectl), YAML, AWS ECR, AWS ELB`

## 📖 Project Overview
Authored manifests to pull images from AWS ECR and deploy scalable pods exposed via Elastic Load Balancers.

## 🚀 Key Learnings
* Configuration and deployment of `Kubernetes (kubectl), YAML, AWS ECR, AWS ELB` in a production-like environment.
* Deep-dive analysis of system logs and network traffic.
* Documentation of technical workflows for architectural clarity.
